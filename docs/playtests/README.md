# Playtests

One file per session, named `YYYY-MM-DD-<milestone>.md` (for example `2026-11-20-m1.md`). Write down what testers did and said, which success criteria in [../roadmap.md](../roadmap.md) passed or failed, and what changes next. Findings that change the design become an edit to [../scope.md](../scope.md) or an ADR.
