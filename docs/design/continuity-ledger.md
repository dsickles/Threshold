# Continuity ledger

Every object, room, fact and motif the story uses, with its life across the chapters. It exists so that nothing appears twice by accident (the first floor-plan draft had a crib put away after the Loss and a "new" crib delivered later). The [narrative-craft skill](../../.claude/skills/narrative-craft/SKILL.md) reads it before any narrative proposal and updates it after.

**Status** is `decided` (Dan agreed, with the date and where it is recorded) or `proposed` (a draft waiting for Dan). Started 2026-10-18; everything below is `proposed` unless it says otherwise.

**Story points** run in play order: Start, Opening beat, Partner, Loss, Novice, Provider, Tuner, Anchor, Mourner, Arrival. "After X" means after chapter X is finished, which is what the core table reads.
